## About the project

This portfolio was built to present my development experience, projects and professional background in one accessible place.

It includes information about my software engineering journey, selected technical work, skills and ways to contact me.

## Key features

- Responsive portfolio layout
- Interactive animations and transitions
- Project and experience showcase
- Technical skills overview
- Contact form powered by EmailJS
- Deployed publicly through Vercel

## Tech stack

- **Framework:** Next.js
- **Frontend:** React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Contact form:** EmailJS
- **Deployment:** Vercel

## Run locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/GabriellaKhayutin1/personalwebsite.git
cd personalwebsite
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
